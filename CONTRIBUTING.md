# Contributing

## Development workflow

- Keep browser-side file handling local and avoid introducing unnecessary uploads.
- Test ZIP creation with multiple files and edge cases before submitting changes.
- Keep the C++ library changes separate from web UI changes.
- Update the README when user-facing behavior or deployment steps change.

## Commit style

Use focused messages such as `feat: add archive progress`, `fix: handle empty selection`, or `docs: clarify local usage`.
